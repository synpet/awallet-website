# awallet-website

Source of **www.awallet.org** — MkDocs + Material for MkDocs, published by GitHub Pages on every push to `main`.

Preview locally:

```sh
python3 -m venv .venv && .venv/bin/pip install -r requirements.txt
.venv/bin/mkdocs serve        # http://127.0.0.1:8000
```

Old Google Sites URLs and heading anchors (`#h.…`) are kept: pages live at the same paths and headings carry their original ids.
