## How can I transfer data from Android to iOS? {#h.wu2nk3k5dmza}

<a id="h.541jllatjb38_l"></a>

### If you used aWallet Cloud on Android {#h.541jllatjb38}

- Install aWallet Cloud in iOS
- Choose the Restore from cloud option on the second initial screen
- Select cloud (Dropbox, Google Drive or WebDAV) and cloud account you've used in the old phone

<a id="h.2mv76dxmnmqj_l"></a>

### If you used aWallet original in Android {#h.2mv76dxmnmqj}

- Create a backup in aWallet original in your Android phone:

  - Unlock the app, press the menu button on the home screen / Backup data file and choose existing or create a new folder
- Use this [guide](https://support.google.com/android/answer/9064445) to connect the phone via a USB cable and copy the data.crypt file to your PC/Mac.
- Install aWallet or aWallet Cloud in iPhone / iPad
- Choose Create new data in the initial screen

  - If you have aWallet Cloud on your iOS device: Choose cloud Dropbox, Google Drive or WebDAV and provide your existing cloud account
- Put the data.crypt file backup to the aWallet or aWallet Cloud iTunes File Sharing folder using [this guide](https://support.apple.com/en-us/HT201301)
- Unlock aWallet, select the Settings tab / Actions / Restore data file

Alternatively if you already have aWallet Cloud installed on your iOS device:

- Copy the data.crypt file backup to your cloud and replace the existing data.crypt
- If you are using Google Drive then copy the file to <https://drive.google.com>. If you are using Dropbox copy the file to <https://www.dropbox.com/home/Apps/aWallet%20Cloud>

  - Note: There must already exist data.crypt file in the cloud and this file must have been created by the app and not by the user. aWallet Cloud will not see the file in the cloud if it was created by the user for the first time.
- Press the sync button in iOS aWallet Cloud home screen to download data from the cloud

## How can I transfer data from iOS to Android {#h.x4yvlkz4s7lc}

<a id="h.8tn2cqtra8gp_l"></a>

### If you used aWallet Cloud on iOS {#h.8tn2cqtra8gp}

- Install aWallet Cloud on Android
- Choose the Restore from cloud on the initial screen
- Select the cloud (Dropbox, Google Drive or WebDAV) and cloud account you've used in the old phone

<a id="h.qfeiwpsosy3b_l"></a>

### If you used aWallet original in iOS {#h.qfeiwpsosy3b}

- In the old iOS phone:

  1. Unlock aWallet, select Settings / Actions, and press the Backup data file.
  2. Connect the iPhone using a USB cable to the computer and start iTunes. Please see [this guide](https://support.apple.com/en-us/HT201301) on how to use iTunes.
  3. In iTunes click on the device icon and select Apps.
  4. Scroll down for the File Sharing section and select aWallet.
  5. Drag and drop the data.crypt file to your computer
- In the new phone:

  1. To find the correct file path do a backup first. Unlock aWallet and in the main screen press menu | Backup data file and choose existing or create a new folder.
  2. Find and replace the created data.crypt file with that from your old phone

     - Use this [guide](https://support.google.com/android/answer/9064445) to connect the phone via a USB cable
  3. In the aWallet main screen press Menu | Restore data file.

<a id="h.m8qbq32tmem9_l"></a>

## How to restore data from the cloud in the new phone {#h.m8qbq32tmem9}

1. Install (or reset) aWallet Cloud on the new phone
2. Select "Restore from cloud" on the second initial screen
3. Select the same cloud and cloud account used on the old phone

   - If you have by mistake chosen "Create new data" after installing aWallet Cloud, [restore an older version](faq-cloud/index.md#h.b0ndjboen6n) of the data.crypt in the cloud.

## How to transfer data without Cloud Pro {#h.vd6gihj68ov1}

Please read first [this guide](https://support.apple.com/en-us/HT201301) on how to use iTunes File Sharing.

- In the old phone:

  1. Unlock aWallet, select Settings / Actions and press the Backup data file.
  2. Connect the iPhone using a USB cable to the computer and start iTunes. Please see [this guide](https://support.apple.com/en-us/HT201301) on how to use iTunes.
  3. In iTunes click on the device icon and select Apps.
  4. Scroll down for the File Sharing section and select aWallet.
  5. Drag and drop the data.crypt file to your computer.
- In the new phone:

  1. Connect the iPhone using a USB cable to the computer and start iTunes. Please see [this guide](https://support.apple.com/en-us/HT201301) on how to use iTunes.
  2. In iTunes click on the device icon and select Apps.
  3. Scroll down for the File Sharing section and select aWallet.
  4. Click the "Add..." button and choose the data.crypt file.
  5. Unlock aWallet app on iPhone, select Settings / Actions and do Restore data file.

## How can I backup data locally? {#h.qomdn4hk9f0}

Note: If you have aWallet Cloud Pro and configured cloud sync you don't need to make local backups.

- Unlock aWallet, select Settings / Actions and press the Backup data file.
- Connect the iPhone using a USB cable to the computer and start iTunes. Please see [this guide](https://support.apple.com/en-us/HT201301) on how to use iTunes.
- In iTunes click on the device icon and select Apps.
- Scroll down for the File Sharing section and select aWallet.
- Drag and drop the data.crypt file to your computer

## How to Export data to CSV {#h.5awiwgyh3w5d}

- Unlock aWallet, select the Settings tab / Actions / Export data to CSV
- Open aWallet or aWallet Cloud iTunes File Sharing folder using [this guide](https://support.apple.com/en-us/HT201301)
- Select the folder named "csv" and use the Save... button at the bottom right corner

<a id="h.pbqup303isi_l"></a>

## How to Import data from CSV {#h.pbqup303isi}

- Prepare folder named "csv" with all CSV files to be imported
- Drag&drop the csv folder to the aWallet or aWallet Cloud iTunes File Sharing folder using [this guide](https://support.apple.com/en-us/HT201301)
- Unlock aWallet, select the Settings tab / Actions / Import data from CSV

## How do I change my password? {#h.nv9cv511z5rv}

- Unlock aWallet
- Select the Settings tab
- Press Actions / Change password
